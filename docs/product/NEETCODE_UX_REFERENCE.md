# NeetCode UX reference for Friday UX-60A

Inspected the current public [NeetCode home](https://neetcode.io/), [roadmap](https://neetcode.io/roadmap), [practice](https://neetcode.io/practice), [courses](https://neetcode.io/courses), and a public course lesson on 2026-09-29 in a rendered browser.

## Observed product patterns

- A compact dark navigation bar gives Courses, Practice, and Roadmap direct access. Active destinations have a quiet filled state.
- The roadmap uses connected topic nodes on a restrained dotted canvas. Choosing a node opens a focused side panel with prerequisites and a scannable problem table. Progress is close to the map and visible numerically as well as graphically.
- Practice uses a category rail, a clear page title and progress summary, list selectors and search, then topic-grouped tables with status and difficulty where those fields exist.
- Courses use category headings and compact cards. A lesson keeps a persistent grouped lesson menu, breadcrumb, progress count, reading content and next lesson action.
- Across these pages, charcoal surfaces, thin borders, moderate radii, off-white text, restrained purple accents, short metadata and predictable hover/selected states prioritize scanning.
- The public course and practice pages remain readable at the inspected desktop viewport; controls have clear text labels and structured headings.

## Friday adoption

Home retains the original Astra Ultra neural brain and the canonical Friday conversation within a disciplined dark shell. Learn uses direct Overview, Roadmap, Practice, Interview and Progress tabs. The canonical map and practice projections use compact cards, visible current/selected states and readable lists. Other workspaces share the same type, spacing, border and navigation language. Every progress value comes from the owning Friday service. Narrow layouts stack content and preserve readable type.

Friday does not copy NeetCode's source, brand, assets, problem text, course text, videos, or exact diagrams. Friday also does not reproduce progress, difficulty, controls or learning state unsupported by Career Forge. The Astra Ultra brain, local runtime and Friday's existing safety boundaries remain Friday's own identity and authority.
